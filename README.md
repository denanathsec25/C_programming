# C Programming

A collection of C programming programs created for learning and practicing fundamental programming concepts. This repository covers topics from basic syntax to pointers, helping beginners build a strong foundation in C programming.

## Topics Covered

* Introduction to C
* Data Types and Variables
* Input and Output Functions
* Operators and Expressions
* Conditional Statements (`if`, `if-else`, `switch`)
* Loops (`for`, `while`, `do-while`)
* Arrays
* Strings
* Functions
* Recursion
* Pointers

## Technologies Used

* C Programming Language
* GCC Compiler

## Getting Started

### Compile a Program

```bash
gcc program.c -o program
```

### Run the Program

```bash
./program
```

## Purpose

This repository serves as a personal learning resource and practice collection for mastering C programming concepts and problem-solving techniques.
